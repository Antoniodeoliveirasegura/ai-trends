Tooling

Claude Ship: Anthropic hands code review, CI fixes and merge approval to agents. It combines Code Review, which is generally available, with two betas. PR Steward fixes failing CI, merge conflicts and review feedback. Claude Approvals applies team-defined merge policy, and Anthropic recommends starting it in observe-only mode. A new /ship command in Claude Code pushes changes, opens the PR and runs the loop. It is for Team and Enterprise customers whose code is on GitHub. Anthropic warns that it can miss bugs and security issues.

Research

OpenAI preprint claims the matrix-multiplication exponent is exactly 9/4, with an upper bound and a matching lower bound. The Nov 24 paper in the openai/math repo extends an October upper-bound result to every field. It also proves that n×n matrices need at least ⌈n9/4/2⌉ nonscalar gates. The previous best upper bound was about 2.3712. The Lean formalization covers only division-free circuits, so the strongest "every field" claim is not fully machine-checked. The paper is unreviewed, and it has no near-term effect on GPU matmul.
