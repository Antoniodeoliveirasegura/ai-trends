Lead Story

Meta Ships Muse Glimmer, a 30B Open Agentic Model Built to Run on a Single Consumer GPU

Meta Superintelligence Labs released Muse Glimmer, a 30-billion-parameter open-weight model distilled from the larger Muse Spark 1.2 via logit distillation, then 4-bit quantized down from roughly 55GB to 18–20GB — small enough to run always-on, locally, inside a 24–32GB VRAM budget on a gaming laptop or desktop. It's Apache 2.0 licensed and live on Hugging Face now, aimed squarely at developers building offline coding agents, function-calling systems, and evaluators that don't want a cloud dependency in the loop.

It matters because it's Meta's clearest bet yet that the next phase of the agent race is local-first, not just cloud-first — and it lands in a week already crowded with agent-autonomy news: Anthropic just made Claude Code's self-driving "auto mode" the default for paid users, and xAI, Alibaba, and ByteDance have each pushed competing capability in the same 10 days. The fight for who owns the on-device agent layer is now explicitly on.
