Lead Story

A Hacker Wired DeepSeek Into an Open-Source Agent and Told It, Once, to Go Attack the Internet

Palo Alto Networks' Unit 42 published details on a China-based actor, "knaithe," who plugged DeepSeek into the open-source Hermes Agent framework and ran a scan-research-exploit pipeline against more than 460 internet-facing systems with a single Telegram command as the only human input. Researchers found the operator's own environment exposed after Hermes accidentally stood up a web server from its home directory — API keys, exploit scripts, target lists, and AI attack logs all sitting in the open.

It matters because it's the clearest documented case yet of "autonomous" offense actually working end to end: Unit 42 confirmed three real compromises via a Citrix NetScaler flaw (CVE-2026-3055), used to pull memory and hijack authentication cookies. The pipeline's manual reach — 460+ systems across Citrix, Apache Tomcat, Marimo Notebook, and Windows IKE VPN — dwarfed what the AI layer accomplished alone, but the fact that a low-cost open model plus an off-the-shelf agent harness got this far, with the labs' own safety controls reportedly blocking equivalent attempts on Claude and GPT, is the part security teams are sitting with today.

Transparency Law Lands on Both Sides of the Atlantic on the Same Day

Today the EU AI Act's Article 50 goes live, requiring any AI system sold in Europe to disclose when users are talking to a machine and to mark synthetic audio, image, video, or text in a machine-readable way. Simultaneously and by design, California's SB 942 (as amended by AB 853) becomes operative, forcing any generative-AI provider with 1M+ California users to embed C2PA-compatible provenance data and offer a free public detection tool — the two effective dates were deliberately aligned.
