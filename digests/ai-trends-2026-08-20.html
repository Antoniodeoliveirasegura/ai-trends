Quiet but Worth Watching

A Benchmark for the Exact Failure Mode Everyone's Suddenly Worried About

"ToolHazard: Scaling Adversarial Environments for Security Evaluation and Alignment of LLM-based Agents" (arXiv:2608.11878, Yutao Mou et al.) built a framework — an Environment Simulator, an Attacker Agent, and a User Simulator — that automatically synthesizes stateful, tool-using environments with realistic injection points and long-horizon adversarial tasks, then stress-tests agents against them via ToolHazard-Bench. It's a quiet infrastructure paper that landed a week before OpenAI's Hugging Face breach and GLM-5.3's Cursor find made exactly this class of failure the week's biggest story.
